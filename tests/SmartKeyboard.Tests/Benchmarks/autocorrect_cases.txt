# Autocorrect benchmark.
#
# One case per line:   previous word | what was typed | what should come out
#
# An empty previous word means the start of a sentence. When the last column
# equals the middle one, the word is correct as typed and must be left alone,
# and changing it counts as a wrong fix.
#
# Lines starting with # are ignored.
